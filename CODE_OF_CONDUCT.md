# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. The canonical text lives at that link; it is referenced rather than copied so it
cannot drift out of date here.

## The short version

Be decent. Assume good faith. Criticise code, not people. Harassment, personal attacks,
demeaning comments and unwelcome attention are not acceptable, in issues, pull requests,
commit messages or anywhere else connected to this project.

## Scope

This applies in all project spaces, and when someone is representing the project in public.

## Reporting

Report conduct issues to the maintainer via a direct message through
[@morrieinmaas on GitHub](https://github.com/morrieinmaas). Reports are handled privately.

This is a small, single-maintainer project, so the "enforcement" machinery described in the
Covenant is one person exercising judgement. Expect a best-effort response, and expect the
maintainer to remove comments, commits, issues or contributors that are not aligned with this
document.
